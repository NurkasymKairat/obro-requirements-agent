# Перевод между своими счетами

Комплект из двух документов: часть A — постановка задачи, часть B — спецификация метода API, на которую ссылается часть A.

## Часть A. Постановка задачи

### Общие сведения

| Поле | Значение |
| :--- | :--- |
| **Наименование задачи** | Перевод между своими счетами с суточным лимитом |
| **Продукт** | Интернет-банк для физических лиц |
| **Владелец продукта** | Департамент розничных продуктов |
| **Версия документа** | — |
| **Дата утверждения** | — |

### Цель
Клиент переводит деньги между своими счетами в интернет-банке без визита в отделение. Банк ограничивает суточный объём переводов, чтобы снизить потери при компрометации учётной записи. Перевод доступен клиенту в любое время суток.

### Термины
Свой счёт — текущий или сберегательный счёт, открытый в банке на имя клиента.

### Функциональные требования
* **П-1.** Клиент выбирает счёт списания, счёт зачисления и сумму. Счета должны различаться.
* **П-2.** Сумма перевода — от 100 ₸ до остатка на счёте списания. Перевод выполняется без комиссии при любых валютах счетов.
* **П-3.** Сумма переводов клиента не превышает 500 000 ₸ в сутки. При превышении лимита клиенту показывается сообщение.
* **П-4.** Если валюты счетов различаются, сумма зачисления рассчитывается по курсу банка на момент подтверждения перевода.
* **П-5.** Списание и зачисление выполняются одной операцией: клиент видит либо оба изменения остатка, либо ни одного.
* **П-6.** Клиент может отменить перевод в течение 5 минут после подтверждения.
* **П-7.** После выполнения перевода клиент видит квитанцию с номером операции, счетами, суммой и временем.

### Нефункциональные требования
* **Н-1.** Перевод должен выполняться быстро и без заметных для клиента задержек.
* **Н-2.** Остатки хранятся в таблице `account_balance` базы PostgreSQL; строка счёта блокируется запросом `SELECT ... FOR UPDATE`.
* **Н-3.** Сервис переводов доступен 99,5 % времени за календарный месяц, не считая согласованных окон обслуживания.

### Требования к данным
По каждому переводу хранятся: номер операции, счёт списания, счёт зачисления, сумма в целых тенге, время и состояние (выполнен, отклонён).

### Требования к безопасности
Будет уточнено после согласования со службой информационной безопасности.

### Требования к интеграции
Интернет-банк выполняет и отменяет перевод через дочерний документ «Перевод между своими счетами — API».

### Критерии приёмки

| Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- |
| На счёте списания 80 000 ₸, переводов за сутки не было | Перевести 30 000 ₸ | Перевод выполнен, остаток счёта списания 50 000 ₸ |
| За сутки переведено 250 000 ₸, на счёте списания 400 000 ₸ | Перевести 300 000 ₸ | Перевод выполнен, остаток счёта списания 100 000 ₸ |
| Счёт списания и счёт зачисления совпадают | Нажать «Перевести» | Перевод отклонён, показана ошибка выбора счёта |

## Часть B. API

Дочерний документ части A: «Перевод между своими счетами — API».

### Общие параметры

| Поле | Значение |
| :--- | :--- |
| **Описание** | Выполнение перевода между счетами одного клиента |
| **Метод** | POST |
| **Адрес** | `/transfers/own` |
| **Авторизация** | Сессия клиента |
| **Пример** | `curl -X POST "$BASE/transfers/own" -d '{"requestId":"a1","sourceAccount":"KZ01","toAccount":"KZ02","amount":1500.50}'` |

### Логика работы
1. Проверить сессию и принадлежность обоих счетов клиенту.
2. Проверить сумму, остаток и суточный лимит.
3. При недостатке средств вернуть 422.
4. При повторном запросе с тем же `requestId` вернуть результат первого запроса без повторного списания.
5. Выполнить перевод и вернуть номер операции.

### Параметры запроса

| Параметр | Тип | Обязательный | Ограничения | Описание |
| :--- | :--- | :--- | :--- | :--- |
| `requestId` | string | Да | 1–36 символов | Ключ идемпотентности |
| `fromAccount` | string | Да | 20 символов | Счёт списания |
| `toAccount` | string | Да | 20 символов | Счёт зачисления |
| `amount` | number | Да | 1–500 000, два знака после запятой | Сумма в валюте счёта списания |

### Поля ответа

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `operationId` | string | Номер операции |
| `state` | string | DONE или REJECTED |
| `fee` | number | Комиссия за конвертацию: 0,5 % суммы при разных валютах счетов |

### Статусы

**200.** Перевод выполнен.  
**400.** Неверные параметры запроса.  
**401.** Сессия недействительна.  
**409.** Запрос с таким `requestId` уже был обработан.

#### 200. Успех
```json
{"operationId":"T-1001","state":"DONE","fee":0}
```

#### 400. Ошибка параметров
```json
{"message":"Проверьте сумму"}
```

#### 409. Конфликт
```json
{"message":"Повторный запрос"}
```
